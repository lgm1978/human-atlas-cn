## V1.2 新增：穴位试验层

在 V1.1 中文术语和肌肉学习卡基础上，增加一个可开关的 3D 穴位学习层。

当前试验内容：
- 22 个常用穴名
- 41 个三维点位（双侧穴按左右分别显示）
- 点击穴位可查看：
  - 中文穴名
  - 国际常用代码
  - 拼音
  - 所属经脉
  - 简要定位
  - 局部解剖提示
- 优先覆盖骨伤科/运动系统学习中较常见的肩、腰、髋、膝、小腿、踝及上肢穴位

### 重要说明

这些三维穴位点是**针对当前 BodyParts3D 成人男性参考模型重新人工近似标定**的学习坐标。

它们：
- 不是 WHO 标准化的三维坐标数据；
- 没有复制 SMPLify-M 的 SMPL-X 顶点映射；
- 没有复制 acu-master 的固定 XYZ 坐标；
- 不用于临床取穴、针刺操作、诊断或治疗决策。

V1.2 暂时只做“穴位点 + 学习卡”。真正沿体表的经络曲线以后再单独实验，避免用简单直线穿过人体造成误导。
