Human Atlas 中文 PWA V1.2｜一键合并更新包

这是从你当前已能正常运行的 V1.0.2 直接升级到 V1.2 的合并包。
不需要先单独安装 V1.1。

包含：
【V1.1 中文术语增强】
- 53 个骨伤科常见肌肉学习条目
- 起点、止点、主要作用、神经支配
- 更多常见肌肉中文名称

【V1.2 穴位试验层】
- 22 个常用穴名
- 41 个三维穴位点（双侧穴分别显示）
- 顶部“穴位试验”开关
- 点击穴位出现学习卡：
  穴名 / 代码 / 拼音 / 所属经脉 / 简要定位 / 局部解剖提示
- 3D穴位点会随人体旋转、缩放
- 本版暂不画经络线，避免简单直线穿过人体

重要：
穴位点坐标是针对当前 BodyParts3D 模型重新人工近似标定，
不是标准临床三维坐标，也没有复制 SMPLify-M 或 acu-master 的坐标数据。
仅用于个人自学和三维解剖学习。

替换方法：
1. 解压本包
2. 把 app、public、README.md、README_CN.md
   按原目录结构复制到本地 human-atlas-cn 仓库根目录
3. Windows 提示时选择“替换目标中的文件”
4. 两个新增文件：
   app/muscle-study-zh.ts
   app/acupuncture-study-zh.ts
5. GitHub Desktop：
   Summary: Human Atlas 中文 PWA V1.2 study layers
   Commit to main
   Push origin
6. 等 GitHub Actions build + deploy 变绿

测试地址：
https://lgm1978.github.io/human-atlas-cn/?v=1.2

- 再点顶部“穴位试验”
- 点击大椎 GV14、肩井 GB21、足三里 ST36、阳陵泉 GB34、委中 BL40、昆仑 BL60
