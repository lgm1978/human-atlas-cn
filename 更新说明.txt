替换方法：
1. 解压本更新包。
2. 将 app、public、README.md、README_CN.md 按原目录结构复制到本地 human-atlas-cn 仓库根目录。
3. Windows 提示时选择“替换目标中的文件”。
4. 注意：app/muscle-study-zh.ts 是 V1.1 新增文件，不是覆盖旧文件。
5. 打开 GitHub Desktop。
6. Summary 建议填：
   Human Atlas 中文 PWA V1.1 muscle study cards
7. Commit to main。
8. Push origin。
9. 等 GitHub Actions 的 build 和 deploy 全部变成绿色。
