# Human Atlas 中文 PWA V1.0 初版

基于原项目 **Human Atlas** 的中文化与 PWA 适配版本。3D 解剖数据仍使用 **BodyParts3D 4.0** 成人男性参考解剖。

## V1.0 已完成

- 主要界面中文化，并保留必要英文标识
- 15 个解剖系统中文名称与中文系统说明
- 常见器官、骨骼、肌肉、血管、神经等结构的中英双语显示
- 中文 / 英文 / FMA 编号联合搜索框架
- 未经人工校对的细小结构不强行机器翻译，保留原英文名
- 支持桌面和移动端原有 3D 交互
- 增加 PWA manifest 与 Service Worker，可添加到手机主屏幕
- 模型文件首次加载后按访问缓存，后续可在缓存完整时离线使用
- Vite 使用相对路径构建，可部署在 GitHub Pages 子目录或其他静态站点

## 术语范围

这是“中文初版”，不是 3,432 个概念的全量医学术语定稿。V1.0 先覆盖常见结构；其余结构保留原英文名与 FMA 编号，后续可逐批按规范解剖学名称校订。

## 本地运行

需要 Node.js 22.13 或更高版本：

```bash
npm ci
npm run dev
```

构建：

```bash
npm run build
```

输出目录：`dist/`
